# TC-SYS-01: Product Creation and Purchase with Coupon (Guest Checkout)

[← Back to System testing](../README.md) · Screenshots: [`screenshots/TC-SYS-01/`](../screenshots/TC-SYS-01/)

## Test case details

| Field | Value |
|---|---|
| Test case ID | TC-SYS-01 |
| Title | Staff creates a product and a coupon; a guest customer buys the product with the coupon; staff completes the order |
| Objective | Verify that staff can create and publish a product and a percentage discount coupon, and that a guest customer can find the product, add it to the cart, apply a valid coupon, handle invalid inputs, and complete checkout using Cash on Delivery. Verify that the order details, product stock, coupon usage, and order status are correctly reflected on the staff and customer sides. |
| Preconditions | 1. The shop is accessible at http://157.85.102.236/shop/. 2. The admin page is accessible at http://157.85.102.236/shop/wp-admin/. 3. The tester has the Group 02 staff account. 4. Cash on delivery is enabled. 5. The customer side is opened in a separate private/incognito window (guest, not logged in). 6. The customer's cart is empty before starting the test. |
| Test data | Run ID: `RUNID` = YYYYMMDD-HHMMSS (the actual test execution date and time). Product: `G02-Test-Watch-RUNID`, Regular price: 500 THB, Stock: 10, Stock management: enabled. Coupon: `g02save10-RUNID`, Discount type: Percentage discount, Amount: 10. Invalid coupon: `g02-invalid`. Customer name: `G02 SYSTester`, Email: `g02.sys01.RUNID@example.com`, Phone: 0800000000, Street address: 99 Test Road, City: Bangkok, State: Bangkok, Postcode: 10400, Country: Thailand. |
| Tested by and date | Thanyakarn Panyadee / 16 November 2026, 16:06:36 |
