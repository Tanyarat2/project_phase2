# TC-SYS-02: Category Browsing, Stock Limit and Order Cancellation

[← Back to System testing](../README.md) · Screenshots: [`screenshots/TC-SYS-02/`](../screenshots/TC-SYS-02/)

## Test case details

| Field | Value |
|---|---|
| Test case ID | TC-SYS-02 |
| Title | Staff creates a limited-stock product; a guest customer browses the product category, attempts to buy more than the available stock, places an order, and staff cancels the order |
| Objective | Verify that staff can create and publish a product in a specific category with limited stock, and that a guest customer can find the product through its category, is prevented from using invalid quantities, and can complete checkout using Cash on Delivery. Verify that staff can cancel the order, that the stock is restored, and that the customer sees the cancellation. |
| Preconditions | 1. The shop is accessible at http://157.85.102.236/shop/. 2. The admin page is accessible at http://157.85.102.236/shop/wp-admin/. 3. The tester has the Group 02 staff account. 4. Cash on delivery is enabled. 5. The customer side is opened in a separate private/incognito window (guest, not logged in). 6. The customer's cart is empty before starting the test. 7. The Accessories category exists in the shop (do not create or edit shared categories). |
| Test data | Run ID: `RUNID` = YYYYMMDD-HHMMSS (the actual test execution date and time). Product: `G02-Limited-Stock-Product-RUNID`, Product type: Simple product, Regular price: 300 THB, Category: Accessories, Stock management: enabled, Initial stock: 3. Invalid quantity: 4 (more than stock). Invalid cart quantity: 0. Valid quantity: 2. Customer name: `G02 SYS02Tester`, Email: `g02.sys02.RUNID@example.com`, Phone: 0800000000, Street address: 99 Test Road, City: Bangkok, State: Bangkok, Postcode: 10400, Country: Thailand, Payment: Cash on Delivery. |
| Tested by and date | Thanyakarn Panyadee / 16 November 2026, 19:46:18 |
